# ANIMA

**Interactive Producer/Engineer Co-Pilot** — a DAW-like co-pilot that proposes actions, applies them live (non-destructively), and explains every step.

## Quick Start

- **No installs / web only:** **[docs/RUN-IN-BROWSER.md](docs/RUN-IN-BROWSER.md)** — run and build ANIMA in Replit, StackBlitz, or GitHub Codespaces.
- **Local run:** **[SETUP.md](SETUP.md)** — Node.js on your machine (no Git required).

## MVP goal

Produce a hook from scratch while teaching: 4 tracks, Action Timeline + undo, live effects (EQ/Comp/Reverb), “make it bouncier,” tutor overlay, export MIDI + blueprint + recipe.
